# Comfort Design — сайт студии дизайна интерьера (Брест)

Одностраничный сайт для студии **Comfort Design** / Елены Жебрун.
Без сборки и зависимостей: статические файлы, которые можно положить на любой
хостинг или GitHub Pages и открыть.

```
comfort-design/
├── index.html              вся разметка (RU) + микроразметка Schema.org
├── robots.txt · sitemap.xml · site.webmanifest
└── assets/
    ├── css/style.css       дизайн-система и все стили
    ├── css/fonts.css       локальные шрифты (без обращений к Google)
    ├── fonts/*.woff2       Unbounded + Onest, только latin + cyrillic
    ├── js/main.js          анимации, меню, попап связи, галерея, переключение языка
    ├── js/i18n.js          английский словарь (русский лежит в разметке)
    └── img/                фотографии, og-превью, иконки
```

---

## 1. Что нужно заменить перед публикацией

Это единственный обязательный шаг. Всё перечисленное сейчас стоит заглушками.

| Что | Где | Сейчас |
|---|---|---|
| **Телефон** | `index.html` — поиск по `+375000000000` | `+375 (00) 000-00-00` |
| **WhatsApp** | тот же номер в ссылке `https://wa.me/375000000000` — **без `+` и пробелов** | заглушка |
| **Instagram Direct** | `https://ig.me/m/comfort_design_brest` — проверить, что ник актуален | рабочая ссылка |
| **Почта** | поиск по `hello@comfortdesign.by` | заглушка |
| **Домен** | поиск по `comfortdesign.by` — `canonical`, `og:url`, `hreflang`, `sitemap.xml`, `robots.txt` | заглушка |
| **Часы работы** | `foot.hours` в разметке и `openingHoursSpecification` в JSON-LD | Пн–Сб, 10:00–19:00 |
| **Проекты** (4 шт.) | секция `#work` — названия, описания, тип/площадь/город/год | вымышленные примеры |
| **Отзывы** (3 шт.) | секция `#reviews` | вымышленные примеры |
| ~~Фотографии~~ | `assets/img/` | ✅ на месте, все 8 кадров |

Английские версии тех же строк лежат в `assets/js/i18n.js` по тем же ключам
(`work.t0`, `q.t0`, `f.name` и так далее). Меняете русский в `index.html` —
поменяйте и английский по ключу, иначе переключатель покажет старый текст.

Цифры в блоке статистики (`6 этапов`, `12 разделов`, `2–4 варианта`, `РБ`)
описывают процесс, который уже расписан на странице, — их менять не нужно,
если процесс не изменится.

## 2. Фотографии

Каждый кадр на сайте сначала показывается как **архитектурный чертёж** —
он нарисован в SVG прямо в разметке и анимируется при прокрутке. Как только
в `assets/img/` появляется файл с нужным именем, чертёж плавно растворяется
и на его месте проявляется фотография. Код менять не нужно.

**Все восемь кадров уже стоят на местах** (`.webp`, суммарно 1,3 МБ).
Список имён и пропорций — в [`assets/img/README.md`](assets/img/README.md).

Одна оговорка: исходники пришли в 1448 px по длинной стороне. На обычном
экране это хорошо, на Retina крупные кадры — hero и «Свет» — будут чуть
мягче идеального. Если захотите резкости, перегенерируйте их в 2× и
положите поверх под теми же именами, код менять не нужно.

Если своих фотографий пока нет, в [`PROMPTS.md`](PROMPTS.md) лежат готовые
запросы для генерации — по одному на каждый кадр, копируются целиком.

Если фотографии для какого-то блока нет — там просто останется чертёж.
Ничего не ломается и не показывает «битую картинку».

**Важно:** после замены фото поправьте атрибут `alt` у соответствующего
`<img>` в `index.html` — опишите реальный объект. Это влияет и на поиск,
и на доступность.

## 3. Заявки — без формы

Формы на сайте нет намеренно: кнопки «Обсудить проект» и «Оставить заявку»
открывают всплывающее окно с прямыми каналами связи.

| Канал | Куда ведёт | Где править |
|---|---|---|
| Instagram Direct | `ig.me/m/comfort_design_brest` | `index.html`, поиск `ig.me` |
| WhatsApp | `wa.me/375000000000` | поиск `wa.me` |
| Звонок | `tel:+375000000000` | поиск `+375000000000` |
| Почта | `mailto:hello@comfortdesign.by` | поиск `hello@` |

Те же четыре кнопки продублированы в секции «Связаться» внизу страницы,
а на телефонах внизу экрана висит кнопка «Написать нам».

Если нужен Telegram — добавьте пятый пункт в список `CHANNELS`
(он собирается один раз и используется и в попапе, и в секции).

Хотите вернуть форму — это отдельная работа: понадобится приёмник заявок
(Formspree, бот, CRM). Сейчас ни одна заявка никуда не уходит, кроме
мессенджера, который выбрал клиент.

## 4. Публикация

**GitHub Pages:** Settings → Pages → Source: ветка и папка `/comfort-design`.
**Любой хостинг:** скопировать содержимое папки в корень сайта.

Рекомендуемые заголовки (если хостинг позволяет): кэшировать `assets/`
на год (`Cache-Control: public, max-age=31536000, immutable`), а `index.html` —
не кэшировать.

## 5. Что уже сделано для поиска и доступности

* уникальные `title` / `description`, canonical, Open Graph и Twitter Card;
* `hreflang` для русской и английской версии, `sitemap.xml`, `robots.txt`;
* микроразметка Schema.org: `InteriorDesignBusiness`, `WebSite`, `FAQPage`,
  `BreadcrumbList` — блок вопросов может попасть в расширенный сниппет Google;
* og-превью 1200×630 и иконки PWA;
* шрифты локальные (быстрее и без передачи данных Google), подгружаются только
  латиница и кириллица — 100 КБ на все начертания;
* семантическая разметка, один `h1`, порядок заголовков без пропусков,
  ссылка «к содержанию», видимый фокус, подписи у всех полей формы;
* контраст текста проверен по WCAG 2.1 AA;
* `prefers-reduced-motion` отключает все анимации, страница остаётся в
  финальном состоянии;
* адаптив проверен на 320 / 360 / 390 / 768 / 1024 / 1440 / 1920 px;
* прокрутка держит 60 кадров в секунду — тяжёлые эффекты (режимы наложения,
  широкие тени на больших блоках, постоянно работающие анимации) убраны
  намеренно, при доработках стоит это проверять.

## 6. Дизайн-система

Все цвета, шрифты, отступы и тайминги — переменные в начале `assets/css/style.css`.

| | |
|---|---|
| Штукатурка (основной фон) | `#e8e5df` |
| Бумага (карточки) | `#f4f2ed` |
| Графит (тёмные секции) | `#16130f` |
| Латунь (акцент) | `#9e7b45`, для мелкого текста `#7d5e2f` |
| Заголовки | Unbounded |
| Текст | Onest |
| Скругления | 14 / 20 / 28 px, кнопки — капсулы |

Тёмная секция получается классом `t-dusk` на `<section>` — все вложенные
компоненты переключают цвета сами.

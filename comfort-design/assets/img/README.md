# Фотографии / Photographs

Каждый кадр на сайте сначала показывается как архитектурный чертёж.
Как только файл с нужным именем появляется в этой папке — чертёж плавно
растворяется и на его месте проявляется фотография. Менять код не нужно.

| Файл           | Где используется            | Пропорции | Рекомендуемый размер |
|----------------|-----------------------------|-----------|----------------------|
| `hero.jpg`     | первый экран                | 16:9      | 2400 × 1350          |
| `elena.jpg`    | портрет автора              | 3:4       | 1200 × 1600          |
| `work-1.jpg`   | проект 01                   | 4:3       | 1800 × 1350          |
| `work-2.jpg`   | проект 02                   | 4:3       | 1800 × 1350          |
| `work-3.jpg`   | проект 03                   | 4:3       | 1800 × 1350          |
| `work-4.jpg`   | проект 04                   | 4:3       | 1800 × 1350          |
| `plan.jpg`     | раздел «Процесс»            | 4:3       | 1600 × 1200          |
| `light.jpg`    | секция «Свет» (курсор-лампа)| 16:9      | 2400 × 1350          |
| `og.jpg`       | превью для соцсетей         | 1.91:1    | 1200 × 630           |
| `icon-192.png` | иконка PWA                  | 1:1       | 192 × 192            |
| `icon-512.png` | иконка PWA                  | 1:1       | 512 × 512            |
| `apple-touch-icon.png` | иконка iOS          | 1:1       | 180 × 180            |

Нет своих фотографий? В `PROMPTS.md` в корне проекта лежит готовый
запрос под каждый файл из таблицы.

Советы:
* сохраняйте в **WebP или AVIF** и меняйте расширение в `index.html` — вес упадёт в 2–4 раза;
* держите вес одного кадра **до 300 КБ**, hero — до 450 КБ;
* для `light.jpg` берите кадр с выраженным тёплым светом — эффект «курсор-лампа»
  показывает его из темноты, и чем контрастнее свет, тем сильнее работает;
* `alt` каждого изображения уже написан в `index.html` — при замене фото
  поправьте его под реальный объект, это важно для поиска.
